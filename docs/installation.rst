Installation
============

Pip (PyPI)
----------

.. code-block:: bash

   pip install grplot

Conda
-----

.. code-block:: bash

   conda install -c conda-forge grplot

How to Update
-------------

Pip (PyPI)
~~~~~~~~~~

.. code-block:: bash

   pip install --upgrade grplot

Conda
~~~~~

.. code-block:: bash

   conda update grplot

Version
-------

.. code-block:: python

   import grplot

   help(grplot)
